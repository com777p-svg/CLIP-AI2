# CLIP AI PRO

مشروع Android أولي لمحرر فيديوهات باستخدام Kotlin وJetpack Compose وMedia3.

## الموجود في هذه النسخة
- اختيار فيديو واحد أو عدة فيديوهات من الهاتف.
- معاينة الفيديو المحدد.
- اختيار نسبة الأبعاد: 9:16 و16:9 و1:1.
- اختيار جودة مستهدفة: 1080p و720p و480p.
- سير GitHub Actions لبناء APK تجريبي.

## ما لم يكتمل بعد
القص الفعلي، دمج المقاطع، وتصدير ملف MP4 ليست مفعّلة في هذه النسخة.

## البناء
يعمل GitHub Actions عند كل Push إلى main. بعد نجاح البناء يمكن تنزيل APK من Artifacts.
